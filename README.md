# Faris Miqdad - Portfolio Website (movlution.github.io)

Website portofolio pribadi modern dan responsif untuk **Faris Miqdad**, mencakup profil pengembang game (Unity / C#), rekayasa perangkat lunak, proyek-proyek GitHub pilihan, serta sinkronisasi ringkasan profil LinkedIn.

## 🌐 Live URL
- **GitHub Pages:** [https://movlution.github.io/](https://movlution.github.io/)

## 🛠️ Tech Stack
- **HTML5 & CSS3** (Semantic layout)
- **Tailwind CSS** (Utility-first styling, glassmorphism UI)
- **Lucide Icons** (Modern iconography)
- **Google Fonts** (Plus Jakarta Sans & JetBrains Mono)
- **GitHub Pages** (Hosting & deployment)

## 📁 Struktur Proyek
- `index.html`: Berkas utama halaman portofolio satu halaman (*single-page application/showcase*).
- `README.md`: Dokumentasi repositori.

## ✏️ Cara Mengubah / Memperbarui Konten LinkedIn & Proyek
Cukup edit berkas `index.html`:
1. Bagian **Experience & Education** (`#experience`): Masukkan riwayat pekerjaan, magang, atau lisensi terbaru dari profil LinkedIn.
2. Bagian **Featured Work** (`#projects`): Tambahkan proyek atau game baru yang baru dirilis.
3. Push ke branch `main`, dan GitHub Pages akan otomatis ter-deploy.

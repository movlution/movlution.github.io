Membangun Particle System di Unity UI Toolkit: Menjembatani Tech Art & UI Engineering

FM
Faris Miqdad Al Barro'
Unity Developer & Technical Artist • Founder @ Mainra Games

Bagi developer yang bermigrasi dari Unity UGUI ke sistem modern UI Toolkit (UIElements), salah satu kendala terbesar yang sering dihadapi Technical Artist adalah: "Bagaimana cara merender efek partikel langsung di atas elemen UIBuilder?"

Di UGUI tradisional, kita biasa menggunakan Canvas dengan mode Screen Space - Camera lalu meletakkan komponen ParticleSystem di antara layer kamera. Namun di UI Toolkit, rendering UI ditangani melalui pipeline retain-mode berbasis vector & batching vertex khusus, sehingga objek 3D atau Shuriken particle di hierarchy tidak langsung digambar di atas visual element.

Tantangan Teknis: Kamera Ganda vs Komposisi Terisolasi

Solusi naif yang sering dipakai banyak tim adalah membuat kamera kedua khusus partikel lalu mengombinasikan target render texture ke UI raw image. Sayangnya, trik ini memiliki banyak kekurangan:

  • Overhead Drawcalls & GPU Memory: Render texture resolusi penuh di perangkat mobile (Android/iOS) sangat memboroskan fillrate dan bandwith memori.
  • Sinkronisasi Transform Koordinat: Menghitung posisi koordinat partikel di dunia 3D terhadap pixel bounding box UI Toolkit saat resolusi layar dinamis berubah sering kali menyebabkan offset dan desinkronisasi.
  • Workflow Iterasi yang Lambat: Desainer UI tidak bisa melihat preview efek partikel langsung di jendela UIBuilder tanpa menjalankan mode Play (Playmode).

Solusi Kami: Package UI-Toolkit-Particle-System

Melalui riset di studio MAINRA Games, kami merancang dan merilis package open-source UI-Toolkit-Particle-System yang kini tersedia secara resmi di OpenUPM.

Pendekatan utama yang kami gunakan adalah memetakan siklus hidup particle emitter dan menghasilkan representasi mesh quad langsung ke pipeline tessellation UI Toolkit dengan custom MeshWriteData atau menginjeksi render order shader material yang kompatibel dengan UI Toolkit canvas rendering context. 

// Contoh registrasi VisualElement partikel di UIBuilder
using MainraGames.UIToolkitParticle;
using UnityEngine.UIElements;

public class InventoryRewardModal : VisualElement
{
    private UIParticleEmitter rewardBurst;

    public void TriggerSuccessEffect()
    {
        rewardBurst = this.Q<UIParticleEmitter>("reward-particles");
        rewardBurst?.Play();
    }
}

Hasil & Keuntungan di Production

Dengan pendekatan native UI Toolkit ini, performa game kami meningkat drastis:

  • Nol Setup Kamera Tambahan: Partikel langsung berada dalam hierarchy UI yang sama dengan tombol, panel, dan popup modal.
  • Hemat Baterai & Performa Ringan di Mobile: Tidak ada alokasi fullscreen render texture terpisah, menjaga frame rate tetap stabil di 60 FPS pada pengujian perangkat Android menengah ke bawah.
  • Open Source untuk Komunitas: Kami mendistribusikannya via OpenUPM agar seluruh komunitas game developer Indonesia dan global dapat memanfaatkannya dengan mudah cukup satu baris konfigurasi package manager.

Kesimpulan

Menjembatani batas antara rekayasa software dan keindahan seni visual (Technical Art) selalu menuntut pemahaman mendalam tentang bagaimana engine menangani grafik di bawah kap mesin. Anda dapat mengecek kode sumber lengkap, dokumentasi instalasi, dan sample scene langsung di repositori open-source GitHub kami.
